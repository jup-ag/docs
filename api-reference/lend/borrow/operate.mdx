Builds a base64-encoded unsigned versioned transaction for any borrow action on a vault position. Body: vaultId, positionId, signer, colAmount, debtAmount, optional positionOwner; optional param market. Positive colAmount deposits collateral and positive debtAmount borrows; negative values withdraw collateral and repay debt, so one call can deposit and borrow, or repay and withdraw, together. Returns nftId and transaction."
